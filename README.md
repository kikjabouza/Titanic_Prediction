# 🚢 Titanic Survival Prediction - Data Mining Project

## 📌 Description du projet

Ce projet de data mining vise à **prédire la survie des passagers du Titanic** à partir de leurs caractéristiques (âge, sexe, classe, etc.).

Il inclut un pipeline complet de :
- 🔍 Traitement des données
- 📊 Analyse exploratoire
- 🤖 Comparaison de plusieurs modèles de machine learning

### Algorithmes utilisés
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest
- Decision Tree
- Naive Bayes
- Logistic Regression
- Gradient Boosting

L'objectif est de **comparer leurs performances** et identifier le modèle le plus efficace pour la classification.

## ⚙️ Pipeline du projet

1. **Exploration et compréhension** du dataset Titanic
2. **Nettoyage des données** (valeurs manquantes, encodage, normalisation)
3. **Analyse des corrélations** et visualisations
4. **Entraînement** de plusieurs modèles de classification
5. **Comparaison des performances** (précision, recall, F1-score, etc.)
6. **Sauvegarde** du meilleur modèle
7. **Documentation** et présentation finale

---

## 📈 Objectif

Développer un **modèle prédictif robuste** capable de prédire la survie d'un passager du Titanic avec la meilleure précision possible, en comparant les avantages et inconvénients de différents algorithmes de machine learning.
