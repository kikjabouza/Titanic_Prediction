🚢 Titanic Survival Prediction - Data Mining Project
📌 Description du projet

Ce projet de data mining vise à prédire la survie des passagers du Titanic à partir de leurs caractéristiques (âge, sexe, classe, etc.).

Il inclut un pipeline complet de traitement des données, d’analyse exploratoire et de comparaison de plusieurs modèles de machine learning.

Les algorithmes utilisés sont :

K-Nearest Neighbors (KNN)
Support Vector Machine (SVM)
Random Forest
Decision Tree
Naive Bayes
Logistic Regression
Gradient Boosting

L’objectif est de comparer leurs performances et identifier le modèle le plus efficace pour la classification.

🧠 Contenu du projet

Voici l’arborescence et la description des fichiers :

📁 images/
   └── Contient les visualisations générées (graphes, analyses, corrélations, etc.)

📄 project_python.ipynb
   └── Notebook principal contenant :
       - Analyse exploratoire des données (EDA)
       - Nettoyage et préparation du dataset
       - Feature engineering
       - Entraînement des modèles ML
       - Évaluation et comparaison des performances

📄 meilleur_modele_pret.pkl
   └── Modèle entraîné sauvegardé (pickle)
       → utilisé pour la prédiction finale

📄 Rapport_ML_Python.pdf
   └── Rapport détaillé du projet :
       - méthodologie
       - résultats
       - interprétation des modèles


⚙️ Pipeline du projet
Analyse et compréhension du dataset Titanic
Nettoyage des données (valeurs manquantes, encodage…)
Analyse des corrélations et visualisation
Entraînement de plusieurs modèles de classification
Comparaison des performances
Sauvegarde du meilleur modèle
Documentation et présentation finale

📈 Objectif

Développer un modèle capable de prédire la survie d’un passager du Titanic avec la meilleure précision possible en comparant plusieurs algorithmes de machine learning.
